## Customize
Search for `Nafeu Mollick`, `hello@nafeumollick.example`, and the portfolio case-study text in `index.html` and replace with your real details.

## Adding review photos
The Reviews section is set up to display a photo for each testimonial. To add one:
1. Get permission from the actual client to use their photo.
2. Save it as a square JPG (roughly 160x160px works well).
3. Name it `reviewer-1.jpg`, `reviewer-2.jpg`, `reviewer-3.jpg`, or `reviewer-4.jpg` (matching the review it belongs to, top-left to bottom-right).
4. Drop it into `img/reviews/`.

Any review without a matching file automatically falls back to the generic icon — no HTML/CSS editing needed. Also update the placeholder name/title text next to each photo in `index.html` to match.
